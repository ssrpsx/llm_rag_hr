## ลำดับที่แนะนำตอนสาธิต
1. ข้อ 1 → 2: ถามเหมือนกัน ได้คำตอบต่างตามบริษัท (ระบบกรองด้วยบริษัทของผู้ใช้ก่อนค้นหา)
2. ข้อ 3, 6: ตัวอย่างนโยบายเฉพาะธุรกิจ
3. ข้อ 10: ภาษาอังกฤษ ชี้ให้เห็นว่า Dense (BGE-M3) ช่วยกรณีคำไม่ตรง
4. เปิดแท็บ Pipeline Trace ของข้อ 9: ดู Funnel และคะแนน Dense / BM25 / Rerank
