# เกณฑ์เงินเดือน และระดับตำแหน่งของไทยเทค — ไทยเทค ซอฟต์แวร์

เอกสารนี้กำหนดเกณฑ์เงินเดือน (salary band) สำหรับทุกตำแหน่งในองค์กร ระดับตำแหน่ง อัตราปรับเงินเดือนประจำปี และช่วงโบนัส เป็นเอกสารที่จำกัดสิทธิการเข้าถึงสำหรับฝ่ายทรัพยากรบุคคลและผู้บริหารระดับสูงเท่านั้น พนักงานทั่วไปและผู้จัดการไม่สามารถอ่านเอกสารนี้ได้

## ระดับตำแหน่ง และนิยามแต่ละระดับ
ไทยเทคแบ่งระดับตำแหน่งของพนักงานออกเป็น 5 ระดับ ประกอบด้วย Junior หมายถึงพนักงานที่เพิ่งเริ่มทำงานหรือมีประสบการณ์ทำงานน้อยกว่า 2 ปี Mid คือพนักงานที่มีประสบการณ์ทำงานประมาณ 2–5 ปี Senior คือพนักงานที่มีความเชี่ยวชาญสูงและสามารถปฏิบัติงานได้อย่างอิสระ Manager คือผู้จัดการฝ่ายที่มีหน้าที่ดูแลทีมและรับผิดชอบผลงานของทีม และ Executive คือผู้บริหารระดับสูงของบริษัทที่รับผิดชอบกลยุทธ์และทิศทางขององค์กรโดยรวม

## เกณฑ์เงินเดือนแต่ละตำแหน่ง (บาทต่อเดือน)
เกณฑ์เงินเดือนของแต่ละตำแหน่งมีดังนี้ Chief Executive Officer 180,000–220,000 บาท HR Manager 80,000–110,000 บาท HR Officer 28,000–40,000 บาท Engineering Manager 110,000–150,000 บาท Product Manager 95,000–130,000 บาท Sales Manager 85,000–120,000 บาท Software Engineer 45,000–70,000 บาท Senior Software Engineer 75,000–110,000 บาท QA Engineer 35,000–55,000 บาท DevOps Engineer 60,000–90,000 บาท Data Analyst 40,000–60,000 บาท UX Designer 40,000–65,000 บาท Sales Executive 30,000–50,000 บาท วงเงินเหล่านี้ใช้เป็นกรอบในการกำหนดเงินเดือนเริ่มต้นและการปรับเงินเดือนประจำปี

## อัตราปรับเงินเดือนประจำปี และรอบประเมินผล
บริษัทมีการปรับเงินเดือนประจำปีหนึ่งครั้ง โดยอัตราการปรับขึ้นอยู่กับผลการประเมินผลงานของพนักงานแต่ละคน โดยประมาณ 3–7 เปอร์เซ็นต์ของเงินเดือนฐาน รอบการประเมินผลงานมีปีละครั้งในเดือนธันวาคม และผลการประเมินจะนำไปใช้กำหนดเงินเดือนและโบนัสของปีถัดไป พนักงานที่มีผลงานดีเด่นอาจได้รับการปรับเงินเดือนสูงกว่าอัตราปกติ

## ช่วงโบนัสประจำปี
โบนัสผลงานประจำปีของไทยเทคอยู่ในช่วง 1–3 เดือนของเงินเดือนฐาน และจ่ายในเดือนมีนาคมของทุกปี จำนวนโบนัสที่แต่ละคนได้รับขึ้นอยู่กับระดับตำแหน่ง ผลงานส่วนบุคคล และผลประกอบการของบริษัทในปีที่ผ่านมา ผู้บริหารระดับสูงอาจได้รับโบนัสในอัตราที่แตกต่างจากพนักงานทั่วไปตามผลประกอบการของบริษัท
